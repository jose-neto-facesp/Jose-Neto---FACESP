# José Neto - Agente PFFOR FACESP

Site de apresentação e venda de serviços para empresas da Baixa Mogiana (interior de SP).

## Estrutura

- `index.html`: página principal
- `css/style.css`: estilos (responsivo, contraste WCAG AA)
- `js/main.js`: menu do celular e links do WhatsApp com mensagem pronta

Site estático em HTML, CSS e JavaScript puros, sem frameworks e sem etapa de build.

## Como visualizar

Abra o `index.html` no navegador.

## Publicação no GitHub Pages

Envie os arquivos para um repositório e ative o GitHub Pages em *Settings > Pages*, usando a branch principal e a pasta raiz.

## Pendências

Procure por `[PREENCHER]` no `index.html`:

- Foto profissional (seção Início)
- Explicação do credenciamento PFFOR e tempo de atuação (seção Sobre)
- Endereço do site oficial da FACESP (rodapé)
